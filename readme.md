# LaserGRBL (Việt hóa) - build trên GitHub

Repo này không chứa mã nguồn LaserGRBL. Mỗi lần build, workflow tải mã nguồn mới nhất từ <https://github.com/arkypita/LaserGRBL>, chạy `viet_hoa.py` (tạo các file `.vi.resx` từ `vi_translations.json`, đặt tiếng Việt làm ngôn ngữ mặc định, thêm mục "Tiếng Việt" vào menu Ngôn ngữ) rồi build bằng MSBuild.

Hướng dẫn: xem `BUILD_GITHUB.md`.
